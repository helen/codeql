# 0.0.1

## New Features

* Initial release of the CodeQL PHP library.
* Added a comprehensive dbscheme based on tree-sitter-php grammar.
* Added AST library with classes for expressions, statements, declarations, types, and operations.
* Added dataflow and taint tracking infrastructure.
* Added framework models for PHP superglobals, PDO, MySQLi, and built-in functions.
* Added security queries for:
  * SQL injection (CWE-089)
  * Reflected XSS (CWE-079)
  * Path injection (CWE-022)
  * Code injection (CWE-094)
  * Command injection (CWE-078)
